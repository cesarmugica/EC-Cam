# Seguridad / Security

Si encuentras una falla de seguridad en EC-Cam, **no abras un Issue público**. Repórtala en privado desde la pestaña **Security → Report a vulnerability** de este repositorio.

If you find a security issue in EC-Cam, **please don't open a public issue**. Report it privately via **Security → Report a vulnerability** in this repository.

Nunca compartas tu archivo `session.json` ni datos de tu cuenta Tapo. / Never share your `session.json` file or Tapo account data.
